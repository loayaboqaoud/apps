تشغيل التطبيق:
1) للعمل الكامل أوفلاين (Service Worker) لازم يُفتح عبر http(s): ارفع المجلد كما هو على أي استضافة ساكنة (GitHub Pages, Netlify...) أو شغّل محلياً:  python3 -m http.server 8000  ثم افتح http://localhost:8000
2) من الجوال افتح الرابط ثم "إضافة إلى الشاشة الرئيسية" (يعمل ملء شاشة وأوفلاين).
3) فتح index.html مباشرة يشتغل أيضاً (بدون تخزين أوفلاين تلقائي).
الخط: QCF4 (مصحف المدينة، مجمع الملك فهد) - لا يجوز إعادة توزيعه بدون إذن الجهة المالكة.

التحليلات (Umami):
1) أنشئ موقعاً في Umami Cloud أو استضف نسخة Umami على خادمك. اختر نطاق الموقع في لوحة Umami ليطابق نطاق التطبيق فقط.
2) انسخ Website ID العام من إعدادات الموقع إلى UMAMI_WEBSITE_ID في config.js. اترك UMAMI_SCRIPT_URL الافتراضي لـ Umami Cloud، أو ضع عنوان script.js من خادم Umami الخاص بك.
3) انشر التطبيق عبر HTTPS. تظهر موافقة التحليلات في أول تشغيل فقط بعد إعداد المعرف؛ لا يُحمّل متعقّب Umami قبل الموافقة، ويمكن تغيير الاختيار من الإعدادات > الخصوصية والتحليلات.
4) Website ID وعنوان script.js معرفات عامة وليسا أسراراً. لا تضع API key أو كلمة مرور لوحة Umami في config.js أو ملفات المتصفح. احمِ حساب الإدارة وقيّد النطاق من لوحة Umami.

تسجل الأحداث زيارات صفحات المصحف وأرقام السور، وفتح المعاني والتفسير، وعدد نتائج البحث (دون نص البحث)، وبدء/إيقاف التلاوة، وأزرار الاستخدام والثيمات، وإعدادات التصميم، وإنشاء/مشاركة الوسائط مع النوع والحجم والأبعاد ومدة الفيديو. لا تُرسل نصوص الآيات أو البحث أو التفسير أو الملفات أو أسماء المستخدمين. عند استخدام لوحة Umami، قد تُعالج المنصة عنوان IP ومعلومات المتصفح/الجهاز والموقع التقريبي؛ راجع سياسة مزود Umami وبلد الاستضافة قبل النشر.

تعرض لوحة Umami الزوار النشطين لحظياً، الصفحات والأحداث والأجهزة والمتصفحات والمواقع الجغرافية المتاحة لديها. لا توفر هذه الإضافة بيانات العمر/الجنس أو تقارير ذكاء اصطناعي، ولا تعمل التحليلات دون اتصال أو على file://. Umami مفتوح المصدر ويمكن استضافته ذاتياً؛ استضافة الخادم قد تكون لها تكلفة.
